# Web-Based-Soil-Monitoring

Tech Stack: CodeIgniter (PHP), Chart.js, HTML, MySQL, DigitalOcean. Badung, Bali
● Developed a dynamic web dashboard utilizing the CodeIgniter framework and HTML to visualize real-time agricultural and
environmental metrics.
● Integrated Chart.js to render interactive multi-sensor time-series line charts, complete with asynchronous API data fetching, custom
tooltips, and responsive layouts.
● Designed and managed an SQL relational database schema to handle large-scale time-series sensor logs across various parameters
● Configured dynamic filtering systems allowing users to sort records by device serial numbers and customized time ranges (from hourly
to monthly)
● Deployed the complete web application stack and database infrastructure to a DigitalOcean cloud server, ensuring high availability and
24/7 online accessibility.
